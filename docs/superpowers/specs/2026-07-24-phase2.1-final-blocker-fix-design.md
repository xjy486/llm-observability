## Problem Summary

| ID | Issue | Impact |
|----|-------|--------|
| BLOCKER-1 | sample_rate=0 → Proxy still reports GATEWAY Span | Orphan spans, broken sampling semantics |
| BLOCKER-2 | Proxy Docker imports SDK source via sys.path | Proxy fails to start in docker-compose |
| P1-1 | unique_users/sessions counted on LLM spans (NULL) | Metrics show 0 users/sessions |
| P1-2 | ObservedStream `__exit__` doesn't close underlying stream | HTTP connection leak |

## Design

### BLOCKER-1: Sampling Gate in `_report_telemetry`

**Current**: `_report_telemetry()` always calls `self.reporter.report(record)`.

**Fix**: Add `sampled: bool` parameter to `_report_telemetry()`. At the top:
```python
if not sampled:
    return
```

**error_always_capture rules**:
- Inherited trace (flags=00): respect upstream — do NOT force report even on HTTP 500.
- Root trace (no upstream): `error_always_capture` + `sample_rate` work normally.

The `should_sample` decision is already computed via `_should_sample_for_ctx()` which handles both cases. We just need to pass it through to `_report_telemetry()`.

**E2E fix**: Replace the weak `trace_count >= 3` assertion with strict before/after count equality:
```python
before_trace_count, before_span_count, before_llm_call_count = ...
# execute sample_rate=0 request
after_trace_count, after_span_count, after_llm_call_count = ...
assert after == before for all three
```

### BLOCKER-2: Common Privacy Module

**Current**: `proxy/config.py` uses `sys.path.insert` to import `privacy_constants` from SDK source tree.

**Fix (Plan A)**: Create `common/privacy/` at repo root:
```
common/
└── privacy/
    ├── __init__.py
    └── constants.py   # SENSITIVE_KEYS + SENSITIVE_REGEX_PATTERNS
```

- SDK `masking.py`: `from common.privacy.constants import ...`
- Proxy `config.py`: `from common.privacy.constants import ...`
- Delete `sdk/python/llm_observability/utils/privacy_constants.py`

**Docker**:

- `proxy/Dockerfile`: `COPY proxy/ common/`

**Regex unification**: Proxy `config.mask_patterns` is replaced by importing `SENSITIVE_REGEX_PATTERNS` from common. Proxy `payload.py` `mask_value()` updated to use compiled patterns from common.

### P1-1: Trace-level Unique User/Session

**Current**: `COUNT(DISTINCT user_id)` on LLM spans (which have NULL user_id).

**Fix**: In `get_metrics()`, add a CTE that computes trace-level user_id/session_id (preferring AGENT span), then count distinct on those:
```sql
WITH trace_dims AS (
    SELECT trace_id,
        COALESCE(MAX(CASE WHEN span_kind='AGENT' THEN user_id END), MAX(user_id)) AS trace_user_id,
        COALESCE(MAX(CASE WHEN span_kind='AGENT' THEN session_id END), MAX(session_id)) AS trace_session_id
    FROM spans WHERE {where_clause}
    GROUP BY trace_id
)
SELECT COUNT(DISTINCT trace_user_id) AS unique_users,
       COUNT(DISTINCT trace_session_id) AS unique_sessions
FROM trace_dims
```

### P1-2: ObservedStream Resource Cleanup

**Fix**: `__enter__` delegates to underlying stream; `__exit__` closes underlying stream first, then finalizes:
```python
def __enter__(self):
    if hasattr(self._stream, "__enter__"):
        self._stream.__enter__()
    return self

def __exit__(self, exc_type, exc_val, exc_tb):
    try:
        if hasattr(self._stream, "__exit__"):
            self._stream.__exit__(exc_type, exc_val, exc_tb)
        elif hasattr(self._stream, "close"):
            self._stream.close()
    finally:
        self._finalize(error=exc_val if exc_type else None)
    return False
```

### P1-3: Reporter stop_sync Timeout Alignment

**Fix**: Replace `future.result(timeout=10.0)` with:
```python
wait_timeout = self.shutdown_timeout + 2.0  # grace period
future.result(timeout=wait_timeout)
```

### P1-4: W3C trace_flags Bit Semantics

**Fix**:
```python
@property
def sampled(self) -> bool:
    try:
        return bool(int(self.trace_flags, 16) & 0x01)
    except ValueError:
        return False
```
