# Phase 2.1 Final Closeout Design

> Date: 2026-07-24
> Baseline: a4e8e164cc2d40858989aaaa355eff63d8f97af5
> Goal: Fix 6 remaining correctness issues, then freeze Phase 2.1.

## Problem Summary

| ID | Problem | Severity |
|----|---------|----------|
| P0-1 | Streaming ContextVar lifetime bound to Span lifetime | Blocker |
| P0-2 | Sampling decision not inherited across full trace | Blocker |
| P1-1 | Reporter shutdown drops queue > batch_size | Correctness |

## Design

### P0-1: Decouple ContextVar lifetime from Span lifetime

**Root cause:** `_do_patch` sets `token = set_context(llm_ctx)` and passes `token` to `ObservedStream`, which only calls `reset_context(token)` on stream finalization. Between `create()` return and stream consumption, the ContextVar still points at the LLM context.

**Fix:** In `_do_patch`, call `reset_context(token)` immediately after `original_create()` returns (both success and error paths). `ObservedStream` no longer receives or holds the token. The span lifecycle (start/end/report) remains tied to stream consumption; only the ContextVar activation is shortened to the create call.

Changes in `sdk/python/llm_observability/instrumentation/openai.py`:
- `_do_patch`: wrap `original_create` in `try/finally` that resets context.
- `ObservedStream.__init__`: drop `token` parameter.
- `ObservedStream._finalize`: remove `reset_context` call.
- Add `__del__` best-effort finalize for early-break scenarios.
- Existing tests that pass `token` to `ObservedStream` must be updated.

### P0-2: Sampling inherited across full trace

**Root cause:** LLM span finalize calls `reporter.report` unconditionally. Proxy `_should_sample` does its own random sample, ignoring the incoming `traceparent` flags.

**Fix:**
- SDK: `SpanContext.sampled` is already inherited from parent. `_finalize_span` and `ObservedStream._finalize` must check `span_context.sampled` before reporting. Since `ObservedStream` no longer holds the context token, it must capture `sampled` at construction time (or store it on the Span).
- Proxy: `resolve_trace_context` already preserves `trace_flags`. `_should_sample` must use the inherited sampled flag when traceparent is present: if `trace_flags` indicates `00` (not sampled), do not report telemetry. When no traceparent (root), apply `sample_rate` as before.

Changes:
- `openai.py`: pass `sampled` to `ObservedStream`; gate `reporter.report` on `sampled`.
- `proxy/handler.py`: `_should_sample` reads `trace_ctx.trace_flags`; when inherited and flags=`00`, return False.
- `proxy/trace_context.py`: add `sampled` property derived from `trace_flags`.

### P1-1: Reporter shutdown drains full queue

**Root cause:** `stop()` calls `_flush()` once, which sends at most `batch_size` records.

**Fix:** `stop()` loops `_flush()` until queue empty or deadline. Add `shutdown_timeout` parameter (default 10s). On timeout, log warning with dropped count.

Changes in `sdk/python/llm_observability/reporter.py`:
- Add `shutdown_timeout` to `__init__`.
- `stop()`: drain loop with deadline.
- `stop_sync()`: pass through timeout.

### P1-2: No-SDK Trace Summary metadata fallback

**Root cause:** Summary SQL uses `MAX(CASE WHEN span_kind='AGENT' THEN session_id END)` — returns NULL when no AGENT span exists.

**Fix:** Use `COALESCE(MAX(CASE WHEN span_kind='AGENT' THEN session_id END), MAX(session_id))` for session_id, user_id, app_name, business_scene.

Changes in `core/storage/db.py` `get_trace_summaries` aggregation query.

### P1-3: Session/User metrics as trace-level filter

**Root cause:** `get_metrics` applies `WHERE session_id=?` directly, excluding LLM spans whose session_id is NULL (metadata lives on AGENT).

**Fix:** When `session_id` or `user_id` is provided, first find candidate trace_ids (any span in trace has the value), then aggregate LLM spans of those traces.

Changes in `core/storage/db.py` `get_metrics`: use CTE subquery for session/user filters.

### P1-4: Unified masking key set

**Fix:** Create `sdk/python/llm_observability/utils/privacy_constants.py` with the canonical sensitive key set and regex patterns. SDK `masking.py` and Proxy `config.py` both import from it (proxy copies the list into its config default). Add `proxy-authorization`, `access_token`, `refresh_token`, `private_key`, `secret_key`, `api-key`, `x-api-key`, `x-auth-token` to the unified set.

Changes:
- New file `sdk/python/llm_observability/utils/privacy_constants.py`.
- `sdk/python/llm_observability/utils/masking.py`: import from constants.
- `proxy/config.py`: import constants for `_default_mask_keys` and `mask_patterns`.
