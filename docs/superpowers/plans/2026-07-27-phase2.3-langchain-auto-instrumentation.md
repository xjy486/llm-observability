# Phase 2.3 LangChain Auto Instrumentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first Framework Auto Instrumentation layer for LangChain v1 `create_agent`, mapping Agent/Model/Tool lifecycles to existing AGENT/LLM/TOOL/GATEWAY Span semantics.

**Architecture:** ObservedLangChainAgent wraps `create_agent` output to create/reuse AGENT Root Trace. LangChainObservabilityMiddleware (AgentMiddleware subclass) hooks `wrap_model_call`/`wrap_tool_call` to create LLM/TOOL child spans. `logical_llm_span_active=True` on the LLM context deduplicates with the existing OpenAI Instrumentor. LangChain is an optional dependency — core SDK works without it.

**Tech Stack:** Python 3.10+, langchain==1.3.14, langchain-core==1.5.1, langgraph==1.2.9, langchain-openai==1.4.0 (E2E only)

## Global Constraints

- LangChain versions: langchain>=1.3.14,<2.0; langchain-core>=1.5.1,<2.0; langgraph>=1.2.9,<1.3; Python>=3.10,<4.0
- LangChain is optional dependency — `import llm_observability` must work without langchain installed
- Reuse Phase 2.1 Tracer.trace(), Phase 2.2 Tracer.tool(), existing masking/size-guard/safe_serialize — NO third masking system
- logical_llm_span_active=True is the dedup key with OpenAI Instrumentor
- AgentMiddleware imported from `langchain.agents.middleware`
- ModelRequest fields: model, messages, system_message, tool_choice, tools, response_format, state, runtime, model_settings
- ModelResponse fields: result (list[BaseMessage]), structured_response
- ToolCallRequest fields: tool_call (dict: name, args, id, type), tool (BaseTool|None), state, runtime
- ExecutionInfo.node_attempt (not attempt_number) for retry tracking
- No new SpanKind, no new DB table, no CHAIN span
- API keys NEVER written to files — only environment variables
- All payload goes through existing safe_serialize + mask_payload + apply_size_guard
- sampled=False: maintain context propagation, skip payload, skip reporter.report
- Fail-open: instrumentation failures must not affect Agent business result

## Compatibility Spike Findings (verified against langchain==1.3.14)

- `from langchain.agents.middleware import AgentMiddleware, ModelRequest, ModelResponse, ToolCallRequest`
- `from langgraph.errors import GraphInterrupt`
- `from langgraph.types import Command`
- `from langgraph.runtime import ExecutionInfo` (has `node_attempt`, `thread_id`, `run_id`)
- Agent type is `CompiledStateGraph` (has invoke/ainvoke/stream/astream)
- Stream chunks: dict keyed by node name (e.g., `{'model': ...}`, `{'tools': ...}`)
- ToolCall is a plain dict: `{'name': str, 'args': dict, 'id': str|None, 'type': NotRequired[Literal['tool_call']]}`
- BaseChatModel does not have `model_name`/`model` as class attrs — use instance attrs or `_llm_type`
